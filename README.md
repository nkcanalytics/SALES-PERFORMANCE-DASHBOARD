# 📊 Sales Performance Dashboard | Excel

## 📌 Project Overview
The Sales Performance Dashboard is an interactive Microsoft Excel project developed to analyze and visualize sales performance across different regions, products, salespersons, and months.

This dashboard helps transform raw sales data into meaningful business insights.

## 🎯 Project Objectives
- Analyze overall sales performance.
- Compare sales across different regions.
- Identify top-performing products.
- Evaluate salesperson performance.
- Analyze monthly sales trends.
- Support data-driven decision-making.

## 🛠️ Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Data Analysis
- Data Visualization
